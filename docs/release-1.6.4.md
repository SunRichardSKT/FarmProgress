# Farm Progress 1.6.4 · F8 界面、搜索距离与鼠标操作

双击原有 `FarmProgress-Setup.exe` 即可 OTA 更新。安装时退出游戏，暂停自动重开脚本。仅查看数据、提醒和方向指引可单端安装；联机数据修改仍需全房同版。

## 方向指引距离

原来就没有固定距离上限，范围是当前已加载、已解锁的农场；默认选择最近目标，所以存在近处待办时不会指向远处。

现在可在 **F8 → 提醒设置 → 方向指引** 中设置：

- 预设 50、100、250、500、1000 格或全农场。
- 自定义 1–10000 格；0 表示全农场，仍以实际可用农场数据为界。
- “就近处理”优先最近目标，“先看远处”优先所选范围内最远目标。
- 收获、浇水、喂食三类标记继续保留。喂食仍优先已断粮动物，范围外目标不会影响范围内选择。

所有距离均按当前角色与目标的水平直线距离估算。指定区域也遵守距离范围；列表和总数仍统计全农场。

## F8 界面

深色背景、统一按钮与分区卡片，按屏幕尺寸调整；较宽窗口使用左侧导航，窄窗口改为顶部导航。

- **农场概览**：三个可点击的收获/浇水/喂食数字卡片、当前指引范围、资产及农场状态。
- **待办与地图**：按类别筛选、搜索品种、查看坐标。默认隐藏没有当前待办的成长区域；选中区域后可一键“指引这里并返回游戏”。
- **提醒设置**：再分方向指引、弹窗提醒、显示与监控。可直接调距离、目标优先级、弹窗间隔、提前提醒、水分阈值、提示大小和扫描间隔，自动保存。
- **报告与工具**：保留报告导出、独立农场副本、联机恢复等功能。

## 鼠标与输入

- F8 打开时显示鼠标，暂时停用当前角色的移动、镜头和普通作业输入。关闭后恢复此前状态，农场模拟继续运行。
- 按 F8、Esc 或右上角关闭按钮返回游戏；数据管理窗口同样接管鼠标。
- 按住 Alt 可临时释放鼠标，点击浮动提示、方向标签或拖动悬浮条；松开后恢复操作。
- 若原本就在原生商店、聊天或对话界面中，保留原生界面的状态；离开农场或卸载插件时释放接管。
- 关闭点击保留短暂输入缓冲，避免同一次鼠标点击落到农场操作上。

数据管理入口仍为 Ctrl + Shift + F10，F9 继续导出报告。

# Farm Progress 1.6.0

适用于 Windows x64 的 Farm Together 一代。此版本包含新联机功能，属于预发布验证阶段；发布为正式下载渠道仅用于让好友的安装器能够找到版本，不代表已完成真实多人测试。

## 好友安装与 OTA 更新

1. 下载并双击 `FarmProgress-Setup.exe`，自动查找游戏、检查 GitHub 最新版本、下载校验并安装，无须填写更新地址或点击安装按钮。
2. 游戏运行中会等待退出后自动继续。若有自动重开房间脚本，安装期间先暂停脚本。
3. 只有找不到游戏或检测到多个安装时，才需要选择一次目录；成功后记住选择。首次安装包含 BepInEx 5 加载器。
4. 显示完成后正常启动游戏。以后双击同一个 EXE 即可在线更新。

无法连接 GitHub 时可点击“离线安装 1.6.0”。离线包不会覆盖更高版本。安装器使用 Windows 自带的 .NET Framework 4.7.2 或更新版本，无需另装现代 .NET SDK；EXE 尚未代码签名。

保留已有 BepInEx 5 和其他 Mod；不覆盖配置和游戏存档。更新前文件备份位于游戏目录 `BepInEx/FarmProgressUpdateBackups`。在线包下载校验 SHA-256，写入失败会尝试恢复原文件。

## 游戏内使用

- **F8**：实时待办、成熟/缺水/喂食提醒、任务相关目标和待办示意图；第二页保留报告、农场复制与联机恢复工具。
- **F9**：导出离线报告与 AI 数据。
- **Ctrl + Shift + F10**：打开或关闭独立数据管理面板；输入聊天等忙碌状态不触发。Esc 关闭。

实时面板分批读取已解锁地格，同圈同品种饲料与整塘收获分别汇总。首次加载只提示待办摘要，之后状态变化时提醒，可关闭悬浮条、静音 10 分钟或关闭提醒。成熟时间为估计，饲料不足时动物 ETA 未知。

管理面板支持金币、钻石、奖牌、票券增减或设置，以及按容量调整分类库存；输入地格坐标可补满该格水分、补满该格动物所属圈的同品种饲料，或使该格作物/花/动物/鱼成熟。补水和补料不扣费用，成熟不自动收获。首版维护与成熟操作按单格/单圈执行，批量区域、持续免浇水、倍率、等级和建筑修改属于后续功能。

房主默认自动授权所有进入房间的访客使用已实现的数据修改功能，不需要白名单或人工批准，配置在重启后保留。房主可在管理面板关闭自动授权。修改始终由房主执行；房主挂机不影响操作，房主游戏退出期间无法修改。

任意数据修改要求**房间内所有客户端安装相同版本并完成握手**。不兼容或正在加载的玩家会使修改暂不可用。发送请求后等待客户端确认；发生差异或结果不明时暂停修改，需核对数据并重新加入。旧会话的请求不会在房间重启后自动重放。

首次修改前，房主在 `BepInEx/FarmProgressAdminBackups` 生成农场二进制快照和操作日志；完整备份恢复需要退出房间后处理。首版不提供通用撤销按钮。

## 验证范围

已通过编译、18 项监控/提醒/数值检查、21 项安装器检查和 18 项模拟传输协议检查，安装器界面已渲染检查。协议检查覆盖自动授权、重复请求、过期预览、旧会话请求、客户端确认失败和超时；不能替代真实 Steam 会话。实际 Unity UI、Steam 多人消息时序、修改后保存与重进仍需房主和好友在真实会话中验证。所有数据修改仅在项目已核对的游戏程序集 MVID 下启用；监控与报告可独立使用。

源代码不包含游戏程序集及游戏反编译代码。构建 Mod 时通过 `build.ps1 -GameDir '游戏目录'` 引用本机游戏和 BepInEx 5 程序集；请准备官方 BepInEx 5.4.23.2 x64 包到 `tools/bepinex`。安装器构建运行 `build-release.ps1`，发布清单固定指向本仓库 Releases。

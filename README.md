# Farm Progress 1.7.0

Farm Together 一代的农场助手：实时监控、任务材料与种养统计、收获/浇水/喂食提醒、方向指引，以及房主授权的数据调整。

## 安装和更新

双击 [FarmProgress-Setup.exe](release/FarmProgress-Setup.exe)，自动查找游戏并从 GitHub 下载最新版。首次安装包含 BepInEx 5；网络不可用时可选择 EXE 内置的离线安装包。

安装前退出游戏，并暂时暂停自动重开房间脚本。找不到游戏时选择包含 `FarmTogether.exe` 的目录，成功后记住选择。以后继续运行同一个 EXE 即可 OTA 更新。

在线下载：[一键更新程序](https://github.com/SunRichardSKT/FarmProgress/releases/latest/download/FarmProgress-Setup.exe) · [发布页面](https://github.com/SunRichardSKT/FarmProgress/releases/latest)。

## 实时监控与指引

- F8 分为农场概览、待办与地图、任务统计、提醒设置、报告与工具，支持按品种搜索和按任务筛选。
- 收获、浇水、喂食各显示一个方向目标，画面内标记目标，画面外显示边缘箭头；绿色收获、蓝色浇水、红色断粮、黄色补料。
- 浮动标签显示操作、目标名称及距离。合并弹窗显示相关品种和数量，多品种简写为“胡萝卜、玉米等3种”；长名称自动缩略，完整名称可在 F8 查看。
- 搜索距离可选 50/100/250/500/1000 格、全农场，或自定义 1–10000 格；0 表示全农场，限当前已加载、已解锁区域。支持就近处理或先看远处。
- 选择待办区域后可点击“指引这里并返回游戏”。目标完成后自动切换，距离为水平直线距离估算。
- 同类提醒合并，默认两次弹窗间隔 30 秒；提前成熟和可补料提醒可单独开启，支持调整大小、静音、水分阈值和扫描间隔。
- 喂食提醒仅计入本轮供料不足、饲料槽能容纳至少一整份，且当前角色有权限、资产足够的动物。断粮但暂不可喂食时可在 F8 查看原因；未来饲料需求仅作为详情预测。
- F8 打开时暂时停用当前角色的移动、镜头和普通作业输入；关闭后恢复，农场模拟继续运行。

植物和动物按格统计收获，鱼按塘统计，喂食按圈内品种分组。动物供料不足时成熟时间未知；其他成熟时间也是估计值。

## 任务统计与种养数量

进入农场后默认显示**任务材料常驻浮窗**，不必打开 F8：每行显示材料、合并待收、已种养、成熟格、补种或可选扩种，并在下一行显示各任务当前进度。按住 **Alt** 可拖动、翻页、折叠或点击“完整统计”。点击“看种养 / 看任务”切换全农场数量与任务材料；位置、折叠和查看模式自动保存。F8 → 提醒设置 → 显示，可调整开关、大小、每页 3–10 行及是否包含已满足材料。

打开 **F8 → 任务统计** 查看完整信息：

- **任务材料合并**：同品种合并待收量取各任务 `max(0, 总需求 - 已收进度)` 的最大值，保留每个任务的独立进度。按物品定义匹配，不把同类资源或同名品种混在一起。
- 列出已种/养、成熟格和一轮缺口；成熟格已经包含在已种/养中。支持搜索、分类、现在可收、一轮缺口、循环可补齐等筛选，点击品种展开任务标题和详细进度，可复制统计文本。
- 作物的一轮缺口是需补种数量；花、树、动物可重复收获，显示按现有规模还需收几轮。一轮缺口只表示可选扩种，避免误导成必须买这么多。
- 鱼按实际鱼种逐格统计，混养塘分别计数；成熟格表示可以尝试捕获。按原生捕获成功率估算可补进度、循环轮数和一轮扩养量，结果可能波动。轮数不代表时间，树还需等待结果季节。
- **全农场种养数量**：统计所有实际作物、花、树、动物、鱼的已种养、成熟、未成熟和未知状态，包括非任务品种。
- 默认沿用实时扫描间隔，支持手动刷新，显示上次完整扫描时间。仅覆盖当前客户端已加载、已解锁区域；状态读取失败时保留占地数量并标为未知。

统计当前农场全部共享任务（含额外订单），不包含已结算历史、新任务的未来需求及个人活动进度；库存和资源翻倍不能替代任务收获次数。F9 的 HTML 报告、`summary.json`、`ai-summary.json` 也包含同一套合并统计。

## 数据调整与访客

房主默认自动授权所有进入房间的访客，配置在游戏或房间重启后保留，无须逐次批准。可在管理面板关闭访客自动授权。

支持金币、钻石、奖牌、票券增减或设置，按容量调整分类库存，单格补水、单格成熟，以及指定动物圈同品种补料。补水和补料不扣费用；成熟不自动发放收获收益。

访客提交请求，由房主 Mod 检查和执行，再同步客户端结果。联机数据修改要求房间内所有客户端安装同版 Mod 并完成握手；只有监控与方向指引时可单端安装。出现不同步或结果不明会暂停修改，需核对数据并重新加入。房间重启后不重放旧请求。

首次修改前，房主在 `BepInEx/FarmProgressAdminBackups` 生成快照和操作记录。首版不提供通用撤销。区域批量修改、持续倍率、等级和建筑修改属于后续规划。

## 报告、副本与联机工具

F9 导出 HTML 地图、资产/库存/任务统计、逐格生长数据和 AI 分析文件，保存在游戏目录 `BepInEx/FarmProgressReports`。农场加载完成后默认自动导出一次；报告为快照，实时数据请看 F8。

AI 数据包括 `ai-summary.json`、`planting-catalog.json`、`growth-tiles.jsonl` 和 `AI-README.md`。Mod 不自动连接 AI 或上传文件。任务按实际收获推进，库存不能直接抵交。

报告与工具页保留“复制当前访客农场为独立本地副本”、联机差异监测和原生重新加入入口。副本不包含房主个人账号资格；复制备份位于 `BepInEx/FarmProgressCopies`。访客拖拉机免耗油为实验功能，默认关闭，不要与外部修改器同时使用。

## 验证与限制

1.7.0 已通过编译和 237 项自动检查，包含 44 项任务统计与浮窗展示检查及 15 项导出检查；另有离线报告浏览器回归与窄屏检查。输入和联机协议使用模拟状态检查；实际 Unity 排版、鼠标操作、镜头跟随和 Steam 多人效果仍需实机验证。

## 本地构建

使用 Windows PowerShell 和 .NET SDK，运行 `build.ps1 -GameDir '游戏目录'` 编译 Mod，引用本机游戏程序集及 `tools/bepinex` 下的官方 BepInEx 5.4.23.2 x64 组件。

`test-live.ps1` 执行当前测试，`build-release.ps1` 生成最新安装 ZIP、OTA 清单和 EXE。构建和测试会按需生成临时目录。发布产物不包含游戏程序集及反编译源码。

卸载时退出游戏，删除 `BepInEx/plugins/FarmProgress`。此项目与游戏厂商无关联。

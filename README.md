## 逐格生长状态与 AI 分析（1.5.0 新增）

按 F9 时额外导出以下文件，全部在原有报告目录中：

| 文件 | 用途 |
|---|---|
| `AI-README.md` | 字段解释、单位、限制和可直接交给 AI 的分析请求 |
| `ai-summary.json` | 紧凑摘要：资产、库存、任务、每种物品的可收获/低水分/成熟时间统计 |
| `planting-catalog.json` | 比较下一轮种植时再读取的已种物品及已解锁作物目录 |
| `growth-tiles.jsonl` | 每行一个作物、花、树、动物或鱼地格，包含具体坐标和生长状态 |
| `summary.json` | 原有完整统计与地图，新增 `growthTiles`；空地与设备仍在 `tiles` 中 |

建议先把 `AI-README.md` 和 `ai-summary.json` 交给 AI，让它规划当前收获、浇水、喂食、任务顺序和下一轮种植。需要逐格路线时再附上或按物品 ID 筛选 `growth-tiles.jsonl`，避免每次都读取整张地图。Mod 不自动连接 AI 或上传文件。

作物/花包含原始含水量、容量、0–1 水分比例、是否灌溉、生长进度、剩余模拟秒数与按正常速度换算的小时数；花额外包含浇水品质积累。树的倒计时基于下次结果季节。动物包含共享饲料，当前饲料不足以供同圈同品种全部长成时，ETA 为 null，同时保留持续供料下的最短剩余成长量。鱼包含逐格计时及整塘可收获状态。

时间是导出时刻的估算，不是固定现实时间保证；浇水、天气、修改器、离线模拟或运行速度变化可能改变结果。汇总中的 `readyAccessible` 和 `lowWaterAccessible` 仅计已解锁区域，样例坐标也只来自这些区域。金额保留字符串精度；种植目录中的基础价格/收益不等于已扣除所有费用、计入所有增益后的净利润。

HTML 地图悬停也会显示水分百分比和预计剩余小时。上述数据不依赖可选详细 JSON 开关。已通过编译、AI 摘要测试与浏览器检查；真实逐格字段导出仍需新版在游戏中运行后验证。

## 访客拖拉机免耗油（1.4.0 实验功能）

先关闭 XiuMaster/其他修改器的所有修改项，再重新加入朋友房间。按 **F8 → 勾选“访客拖拉机免耗油（实验性）”**。默认关闭，仅对你当前的访客角色生效，房主与其他玩家无须安装。本地单人和你自己当房主时不启用。

该功能利用一代原版的单格操作不扣拖拉机燃油的路径，将你的普通多格作业按原顺序拆成单格提交，保留移动操作的源/目标对。房主和其他客户端仍走原版动作执行流程，农场的购买费用、权限和收获收益保持原版规则。你的本地燃油维持可用，关闭后恢复跟踪的正常燃油值。

这是经代码检查和分组测试的尝试性实现，**尚未通过真实双人会话验证**，不保证所有场景下都不会不同步。消息数量会增加。先用少量种植/收获测试，并请房主核对地格和资产；同步监测出现差异时停用并重进。

本功能不支持同步金币、钻石、奖牌、经验倍率、不浇水、不喂食、快速成熟或快速建房。仅改访客内存不能使这些数值变成所有玩家一致的农场状态。请勿同时开启原修改器；本功能不是完整修改器兼容层。详细说明见 `analysis/trainer-compatibility.md`。

## 访客不同步恢复（1.3.0 新增）

在朋友房间出现地图/资产差异时，按 **F8 → “退出并重新加入房主（重新下载农场数据）”**。按钮调用游戏自身的邀请加入流程，重新下载房主的完整农场。房主无须安装此 Mod，但必须在线且允许加入。恢复会暂时离开房间；重进失败可用 Steam 好友列表手动加入。

Mod 观察原生随机状态校验，在发现差异或农场时钟超过 15 秒未收到时提示。种子校验不是全量地图校验，没发现种子差异不等于所有物品完全一致。发现过的分歧不会因下次种子相同而自动宣布恢复，需重新加载农场。

这是已分歧客户端的恢复措施。当前尚未查明最初触发不同步的具体操作，不能保证不再发生。它不修改模拟时钟或随机数，不屏蔽原生检查，不自动反复断线，不将本地副本写回房主。监测与恢复入口目前限定已检查的一代游戏构建；游戏版本改变时会提示未启用。

诊断记录在 `BepInEx/SyncDiagnostics/*.jsonl`。已通过编译与监测状态测试，双人联机中的实际重新加入与修复效果待验证。详细调查见项目 `analysis/multiplayer-desync.md`。

## HTML 任务管理（1.2.0 新增）

报告顶部点击 **“任务管理”**，查看该快照中的全部当前农场任务（不含已结算历史和个人活动任务）。任务卡片显示标题、置顶状态、完成进度条、逐项目标、已计入数量和还需收获数量。整体进度按照游戏任务界面的算法，取各目标完成比例的平均值。

默认按奖牌收益从高到低排列，也可按进度或经验排序；支持按进行中/已达成筛选，以及按任务或目标物品搜索。顶部统计全部当前任务完成后可获得的奖牌和经验，另列已达成任务待自动结算的奖励；这些数值不会重复计入现有资产。

**1 代任务不能用库存直接提交。** 任务按收获指定品种推进，目标达成后由游戏自动结算。因此状态显示“进行中”或“已达成，待自动结算”；仓库中的蔬菜、水果等属于共享资源分类，仅作为参考，不从收获缺口中扣除，也不标成可直接提交。

重启游戏后按 F9 生成的新报告包含任务名称和相关库存分类。旧报告的原始任务 JSON 也能在新版 HTML 中显示进度、缺口及奖励；旧数据缺少名称或库存分类时会显示任务编号或“未提供”，不会猜测。

页面离线可用，不会持续刷新。在游戏中按 F9 可导出新的任务进度。浏览器验证覆盖了奖励精度、排序、筛选、缺口、库存不可抵交、自动结算状态、旧数据兼容、空列表及手机布局；新任务字段在游戏中的实际导出仍需重启插件后验证。

## 将朋友的农场复制到本地（1.1.0 新增）

进入朋友房间，等待农场完全加载后，按 F8，点击 **“同步当前农场到本地（新建副本）”**。等待面板提示保存成功，再退出房间回到主菜单，在农场列表中选择 **“联机副本 日期 时间”** 即可继续游玩。

这是点击时刻的客户端农场快照，每次点击生成独立的新农场，不自动追踪后续变化。只在朋友农场中启用此按钮；导出报告和自动导出不会触发复制。

复制内容包括当前客户端收到的金币、钻石、勋章/缎带、票券、农场等级、物品与配方等级、库存、地块解锁、种植、动物、鱼塘、建筑及其状态、房屋和任务。房主的角色等级、个人活动奖励、Steam 成就和 DLC 所有权不在农场文件中；副本继续使用你自己的账号资格。新副本默认仅本地游玩，点赞和访客权限不冒用房主资料。

副本写入当前玩家的游戏存档容器并登记到农场列表；启用 Steam 云存档时会按游戏原有规则同步。已有农场正文文件不被覆盖。写入前会检查游戏农场列表和实际的 `.data`、`.bak` 文件，选择空位。写入与农场列表更新均通过游戏的存储队列执行。

备份在游戏目录 `BepInEx/FarmProgressCopies/时间-标识/`：`farms.data.before` 等是更新前的列表原始文件，`farm-snapshot.data` 是复制的农场正文，`copy-info.json` 记录名称和位置。写入后校验正文与列表；失败会尝试撤销副本并恢复原列表，恢复失败会在日志中标注备份目录。

游戏中尚未完成真实联机复制和副本进入验证。已通过针对存档位置冲突、重复复制、正文写入失败、列表更新失败及校验失败的独立检查。首次使用后应确认新副本能够正常进入。

## 安装与使用

本机游戏目录：`F:\SteamLibrary\steamapps\common\Farm Together`。

1. 将安装包中的所有内容解压到含 `FarmTogether.exe` 的目录，保持目录结构。已存在 BepInEx 5 的玩家只需复制 `BepInEx/plugins/FarmProgress/FarmProgress.dll`。
2. 重新启动游戏，加入朋友房间，等待加载完成及 8 秒的导出延时。
3. 按 F8 查看资产，点击“打开离线报告”。F9 可以随时导出新的快照。
4. 报告在游戏目录 `BepInEx/FarmProgressReports/年月日-时分秒-毫秒/report.html`。直接用浏览器打开即可，无须联网。

同目录文件：`summary.json` 为统计与地图数据；`farm-detail.json` 为游戏自身序列化的详细状态（只读导出）。JSON 中货币和资源数量以字符串保存，防止浏览器丢失大整数精度。

首次运行后生成 `BepInEx/config/local.farmtogether.progress.cfg`，可以修改按键、关闭进入后自动导出或关闭详细 JSON。报告只在加入或手动刷新时生成，不是持续记录器。

## 解锁状态的含义与边界

“农场等级条件”仅描述该农场等级和前置物品等级是否满足；“当前访客购买状态”调用游戏自身的判断，包含当前玩家的活动和 DLC 资格。它不能证明房主账号的活动奖励解锁情况。房主 DLC 状态单独从游戏收到的 DLC 列表读取。

地图是根据逻辑地格绘制的分类示意图，不是原版美术地图或场景截图。已放置的全部逻辑地格参与统计，不依赖摄像机视野。农场历史累计收获、房主 Steam 成就与未发送到客户端的个人账号数据不作推测。

报告功能只把已收到的数据写入独立报告目录。新增复制功能仅在点击按钮时写入新的本地农场和本地农场列表，不改动正在访问的房主农场或其网络消息。报告的详细 JSON 不是完整的个人账号存档；可游玩的副本由复制按钮生成，不保证跨游戏版本兼容。

## 卸载

退出游戏，删除 `BepInEx/plugins/FarmProgress` 即可卸载本 Mod。报告可自行保留。如果仅为这个 Mod 安装过 BepInEx，可移走加载器 `winhttp.dll` 来停止加载；有其他 Mod 时保留加载器。

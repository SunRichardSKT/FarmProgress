# Farm Progress 1.7.0 · 共享任务材料与全农场种养统计

先退出游戏并暂停自动重开脚本，然后运行原来的 `FarmProgress-Setup.exe` 即可 OTA 更新。进入农场后默认显示任务常驻浮窗，完整统计见 **F8 → 任务统计**。监控和统计可单端使用；联机数据修改仍需房间内所有客户端同版。

## 游戏内常驻浮窗

- 默认常驻显示材料、合并待收、已种养、成熟格、补种或可选扩种，并显示各任务的当前进度。
- 按住 Alt 可拖动、翻页、折叠和点击“完整统计”；位置和折叠状态自动保存。
- 点击“看种养 / 看任务”切换全农场实际品种数量与当前任务材料；种养视图包含非任务品种。
- 默认每页 5 行，材料多时分页，不会一次铺满屏幕。F8 → 提醒设置 → 显示，可调整开关、0.8–1.4 倍大小、每页 3–10 行，以及是否包含已满足材料。
- 鱼的扩养建议带估计标识；可持续品种显示“可选”，作物显示“补种”。长名称和过长进度行缩略，完整信息可在统计页查看。

## 任务材料合并

一次收获会推进所有当前同品种任务，因此合并待收量取各任务剩余数量的最大值，而不是相加，也不是“最大总需求减最大进度”。例如任务分别还差 80、30 个玉米，合并还需收 80 个。

- 列出各材料的合并待收、已种养、成熟格和一轮缺口；每个任务的独立进度保留，点击品种可展开任务标题和详情。
- 已种 50 格玉米，其中 20 格成熟，合并还需 80 个：可先收 20 格，还需补种 30 格。成熟格包含在已种数量中，不重复扣减。
- 支持品种名称/ID 搜索、分类、可收获/一轮缺口/可循环收获筛选、包含已完成目标、复制统计文本和手动刷新。
- 显示上次完整扫描时间，默认沿用实时监控的扫描间隔。

## 花、树、动物与鱼

全农场种养页直接扫描实际地格，按具体品种统计作物、花卉、树木、动物、鱼的已种养、成熟、未成熟和未知状态，包含当前任务没有要求的品种。

花、树、动物可以重复收获。若还需收 60 个苹果，现有 20 棵苹果树，会显示按当前规模收 3 轮；若希望一轮完成，可选加种 40 棵，不会当成必须扩种。轮数不是时间估计，树仍受结果季节影响，动物仍需供料。

鱼按实际鱼种逐格计数，混养池分别统计，整塘能收获不代表每格鱼都成熟。只有成功捕获才推进任务；成熟格是捕获尝试数，可补进度、轮数和扩养量按原生成功率估算，并明确标为估计，实际结果可能波动。

## 报告与范围

F9 的离线 HTML 任务页新增合并统计和种养数量视图，支持搜索、切换查看；`summary.json` 和 `ai-summary.json` 新增 `taskPlan`，与实时页共用计算规则。快照格式升级为 schemaVersion 4，原有任务详情保留。

统计仅覆盖当前客户端已加载、已解锁区域及当前农场共享任务（含额外订单），不含已结算历史、后续新任务和个人活动进度。库存不能抵交，资源收益增益不等于任务计数增益。分批扫描期间其他玩家操作可能造成短暂变化，状态读取失败的格子计入已种养并标为未知。统计不修改农场或任务。

## 验证

编译及 237 项自动检查通过，其中 44 项任务统计与浮窗展示检查覆盖共享缺口、不同任务初始进度、同名不同品种、可重复收获、混养鱼塘、概率边界、未解锁区域、状态读取失败和大整数数量；另有 15 项导出检查及原有提醒、输入、安装、模拟联机检查。

离线报告浏览器检查覆盖合并统计数值、搜索、非任务品种、鱼的估计标识、桌面/窄屏排版，以及原有报告功能。游戏行为依据当前构建的静态实现核对；实际 Unity 面板操作与 Steam 多人效果仍需实机验证。

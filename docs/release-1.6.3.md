# Farm Progress 1.6.3 · 补充收获方向指引

双击原有 `FarmProgress-Setup.exe` 即可 OTA 更新。安装时先退出游戏，并暂时暂停自动重开脚本。

## 收获指引

- 保留原有成熟弹窗，新增绿色浮动收获标记，例如“收获 · 约 8 格”。
- 支持已成熟的作物、树、花和动物，以及可收获鱼塘。
- 画面内标记对应目标上方，画面外显示边缘箭头；跟随玩家相机转动。
- 默认收获、浇水、喂食各显示最近一处，最多三个标记，标签在拥挤时尽量错开。
- 收获后自动切换下一个目标。鱼塘按整体可收获状态指引到最近的鱼塘地格，整塘收完后移除该塘的旧目标。
- 已成熟的动物显示为收获目标，不同时作为喂食目标。

F8 的浮动指引设置可选“收获＋浇水＋喂食”“只指引浇水”“只指引喂食”或“只指引收获”。默认开启全部三类；保留用户已选择的单一类别设置。选择可收获区域后，也能点击“将这个区域设为方向指引目标”。

指引每约 0.4 秒复核当前目标，新成熟目标随分批扫描加入。距离为水平直线距离估算。只读取当前客户端数据，无须房主配合安装；联机数据修改仍要求全房同版。

## 验证

通过编译及 107 项自动检查，其中新增成熟作物/树/花/动物与鱼塘目标、最近收获点、指定区域、收完后切换及整塘失效检查。真实 Unity 画面布局、镜头跟随与 Steam 多人效果仍待游戏内验证。

原有快捷键：F8 监控，F9 导出，Ctrl + Shift + F10 数据管理。方向指引的其他设置和行为见 [1.6.2 说明](https://github.com/SunRichardSKT/FarmProgress/blob/main/docs/release-1.6.2.md)。
